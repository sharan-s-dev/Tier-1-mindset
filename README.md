# The Tier-1 Mindset

> Track DSA patterns, core CS concepts, and software engineering interview readiness.

A personal preparation engine and progress tracker designed to guide an engineer from fundamental data structures and algorithms through to software engineering interview readiness.

---

## 🎯 Overview

Preparing for technical software engineering interviews requires consistent daily execution across multiple domains: algorithmic problem solving, core computer science fundamentals, and system design. 

**The Tier-1 Mindset** provides a structured, distraction-free environment to track progress, visualize milestones, and assess overall interview readiness without relying on fragmented spreadsheets or generic checklists.

---

## ✨ Features

- **Phase 0 Launchpad:** Pre-flight gate designed for active DSA courses (language mechanics, Big-O intuition, standard library templates, and foundational data structures).
- **150-Day Structured Roadmap:** 5 balanced phases covering Arrays, Two Pointers, Trees, Graphs, Dynamic Programming, and Advanced System Architecture.
- **Curated Problem Matrix:** Tracks LeetCode / interview problem solving with pattern classification, difficulty filters, and completion status.
- **CS Core Vault:** Quick-reference and self-testing module for Operating Systems, DBMS, Object-Oriented Design, Computer Networks, and System Design.
- **Readiness Probability Engine:** Multi-factor scoring model that weights problem counts, CGPA thresholds, mock interviews, and project depth into an overall readiness index.
- **Portfolio Project Studio:** Project grading rubric and blueprints emphasizing systems depth (caching, concurrency, containerization, and unit testing).
- **Local Persistence & Data Portability:** All progress is stored locally in the browser (`localStorage`) with one-click JSON backup and restore capabilities.

## 🚀 Getting Started

### Prerequisites

- Node.js (version 18 or higher)
- npm or pnpm / yarn

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/the-tier-1-mindset.git
   cd the-tier-1-mindset
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
